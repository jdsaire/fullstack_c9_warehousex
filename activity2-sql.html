Single Revised SQL Query (Submission Item S2)

Course 9 Capstone prompt P3 asks for a single revised SQL query reflecting optimization. Below is the side-by-side comparison between the unoptimized baseline (Activity 2 Step 2) and the revised query leveraging driving-table inversion and covering index resolution.

Baseline · Unoptimized 
SELECT p.ProductName, SUM(o.Quantity) AS TotalSold
FROM Orders o
JOIN Products p ON o.ProductID = p.ProductID
WHERE p.Category = 'Electronics'
GROUP BY p.ProductName
ORDER BY TotalSold DESC;
Identified Inefficiencies:
  • Full table scan on Orders (unindexed table heap access)
  • Post-join evaluation of Category = 'Electronics' filter
  • Temporary B-tree required for text grouping on ProductName
  • Temporary B-tree required for alias ordering on TotalSold
Optimized · Submission S2 
SELECT p.ProductName, SUM(o.Quantity) AS TotalSold
FROM Products p
JOIN Orders o ON p.ProductID = o.ProductID
WHERE p.Category = 'Electronics'
GROUP BY p.ProductID, p.ProductName
ORDER BY TotalSold DESC;
Key Optimization Techniques:
  • Driving-table inversion: filtered Products leads the join
  • Pure covering index seek via idx_products_category_covering
  • Pure covering index seek via idx_orders_product_qty
  • Zero table heap reads: 100% answered from index leaf pages

Composite Covering Index DDL

-- Composite Covering Index on Products
CREATE INDEX IF NOT EXISTS idx_products_category_covering 
ON Products(Category, ProductID, ProductName);

-- Covering Index on Orders
CREATE INDEX IF NOT EXISTS idx_orders_product_qty 
ON Orders(ProductID, Quantity);
